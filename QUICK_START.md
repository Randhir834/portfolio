## 🎬 What to Check

### 1. **Hero Section** (Top of homepage)
- Watch the text fade in sequentially
- Notice the floating profile image
- See the pulsing glow effect

### 2. **Scroll Down** 
- All sections animate as you scroll
- Counter numbers count up (350+, 6+, etc.)
- Cards scale in with elastic effect

### 3. **Hover Effects**
- Hover over project cards - they lift up
- Buttons have smooth hover animations
- Footer links animate on hover

### 4. **Navigation**
- Click between pages (About, Skills, etc.)
- Watch smooth page transitions
- Scroll down to see "Scroll to Top" button bounce in

### 5. **Mobile View**
- Resize browser window
- All animations work responsively

## 🎨 Files You Can Edit

### Change Animation Speed
Edit: `src/composables/useAnimations.js`
```javascript
duration: 800  // Change to 400 for faster, 1200 for slower
```

### Modify Component Animations  
Edit any component file in: `src/components/`

### Adjust Delays
```javascript
fadeInUp('.element', 200)  // 200ms delay
```
